Opsional: Letakkan file musik instrumental romantis Anda di folder ini dengan nama file:
background.mp3

Contoh path:
public/audio/background.mp3

Catatan:
Jika file background.mp3 belum ditambahkan, aplikasi akan tetap berjalan normal tanpa error dan memutar melodi instrumental lembut bawaan Web Audio API saat pengguna menekan tombol Play.
